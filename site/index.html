Профиль — для всего iPhone

Работает во всех приложениях и браузерах, включая Chrome и Яндекс Браузер.

↓Скачать профиль для iPhone

4 касания и код-пароль. Меньше iOS не позволяет никому.

  1. «Разрешить» — в окне загрузки (открывайте в Safari).
  2. Настройки → вверху «Профиль загружен».
  3. «Установить» → код-пароль.
  4. Ещё раз «Установить». iOS напишет «Не подписан» — честно: чужими сертификатами не подписываем.

Уже стоит другой DNS или VPN? Тогда ещё один шаг: Настройки → Основные → VPN и управление устройством → DNS → Чисто.

Расширения в браузерах на iPhone Apple ставить не даёт — ни в Chrome, ни в других. Поэтому профиль.

Как выключить, если какой-то сайт не открывается: Настройки → Основные → VPN и управление устройством → профиль Чисто → «Удалить профиль». После удаления ничего не остаётся.

Частный DNS — без программ

Android 9 и новее. Работает во всех приложениях и браузерах.

Скопировать и 3 касания в настройках.

⧉Скопировать адрес
  1. Настройки → Сеть и интернет (или «Подключения» → «Другие настройки») → Частный DNS.
  2. Выберите «Имя хоста провайдера частного DNS».
  3. Вставьте адрес и нажмите «Сохранить».

Приложение

Кнопка «вкл/выкл» для всего телефона. Приложение поднимает локальный VPN только для DNS-запросов: остальной трафик идёт напрямую и не записывается.

↓Скачать приложение (APK)
  1. Android спросит про «неизвестный источник» — разрешите для браузера. Это файл с нашего сайта, не из Google Play.
  2. Установите и откройте приложение, нажмите «Включить защиту».
  3. Подтвердите системное окно «Запрос на подключение» — это и есть локальный VPN.

Chrome на Android — за минуту

Реклама и слежка уберутся на сайтах в Chrome. Приложение для всего телефона — в работе.

⧉Скопировать адрес

Скопировать и 3 касания в настройках Chrome.

  1. Chrome → ⋮ (справа вверху) → Настройки → Конфиденциальность и безопасность.
  2. «Использовать безопасный DNS» → включить → «Свой» (или «Выбрать другого поставщика» → «Свой»).
  3. Вставьте адрес — готово, сохранять не нужно.

«Частный DNS» в настройках самого Android сюда не подходит: он требует другой протокол, и интернет пропадёт.

Как выключить, если какой-то сайт не открывается: Chrome → Настройки → Конфиденциальность и безопасность → «Использовать безопасный DNS» → выключить.

Расширение для браузера

Основной способ для сайтов: режет рекламу, прячет баннеры и стены «отключите блокировщик». Chrome, Edge, Яндекс Браузер, Opera, Brave, Firefox.

+Установить расширение

Из магазина — 1 клик. Из архива — 3 шага, один раз.

В магазинах расширения пока нет — ставится из архива с сайта (или файлом из бота @chisto_ads_bot) за три шага:

  1. Распакуйте архив в папку, которую не будете удалять.
  2. Откройте chrome://extensions (в Edge, Opera и Яндекс Браузере адрес тот же) и включите «Режим разработчика».
  3. «Загрузить распакованное» → выберите эту папку.
  1. Откройте about:debugging#/runtime/this-firefox.
  2. «Загрузить временное дополнение» → выберите скачанный архив.
  3. Честно: временное дополнение исчезнет после перезапуска Firefox. Постоянно — только после публикации в addons.mozilla.org.

Другой браузер: архив для Chrome и похожих · архив для Firefox

Как выключить, если какой-то сайт не открывается: значок расширения → «Выключить на этом сайте» или «Поставить на паузу везде».

DNS — по желанию

Режет рекламные домены не только на страницах, но и в программах.

Только браузер: Chrome, Edge, Яндекс Браузер
  1. Настройки → Конфиденциальность и безопасность → Безопасность → «Использовать безопасный DNS».
  2. «Выбрать поставщика» → «Свой» → .
  3. Выключить — там же, переключателем.
Windows 11
  1. Параметры → Сеть и Интернет → Wi-Fi или Ethernet → свойства оборудования → «Назначение DNS-сервера» → Изменить → Вручную.
  2. IPv4 включить, предпочитаемый DNS: .
  3. «DNS через HTTPS» → Вкл (вручную), шаблон: .
macOS — для всех программ
  1. Скачайте тот же профиль, что для iPhone.
  2. Системные настройки → Основные → Управление устройствами (в старых macOS — «Профили») → двойной клик по профилю → Установить, пароль Mac.
  3. Выключить: там же, кнопка «−».
Linux (NetworkManager + systemd-resolved)
  1. В /etc/systemd/resolved.conf: DNS=# и DNSOverTLS=yes.
  2. sudo systemctl restart systemd-resolved.
  3. Проверка: resolvectl query ad.doubleclick.net → 0.0.0.0.
