iPhone и iPad

Защита включается сразу во всех приложениях и браузерах: Safari, Chrome, Яндекс Браузер. Установка — около минуты.

↓Скачать профиль для iPhone
  1. Нажмите кнопку выше (лучше в Safari) и в окне выберите «Разрешить».
  2. Откройте «Настройки» — вверху появится строка «Профиль загружен». Нажмите на неё.
  3. Нажмите «Установить» и введите код-пароль от телефона.
  4. Ещё раз «Установить» — готово.

iOS напишет «Не подписан». Это нормально: подписывать профиль чужим сертификатом мы не стали. Внутри только адрес DNS-сервера, больше ничего.

Частный DNS — без программ

Android 9 и новее. Работает во всех приложениях и браузерах.

Адрес для вставки

  1. Скопируйте адрес из рамки выше.
  2. Настройки → Сеть и интернет (или «Подключения» → «Другие настройки») → Частный DNS.
  3. Выберите «Имя хоста провайдера частного DNS», вставьте адрес и нажмите «Сохранить».

Как выключить: там же — «Частный DNS» → «Автоматически» или «Отключено».

Приложение

Защита для Chrome — за минуту

Реклама и слежка уберутся на сайтах в Chrome. Другие приложения этот способ не защищает — для всего телефона есть «Частный DNS» выше.

Адрес для вставки

  1. Скопируйте адрес из рамки выше.
  2. Откройте Chrome, нажмите ⋮ (справа вверху) → «Настройки» → «Конфиденциальность и безопасность».
  3. Включите «Использовать безопасный DNS» и выберите «Свой» (или «Выбрать другого поставщика» → «Свой»).
  4. Вставьте адрес в поле. Сохранять ничего не нужно.

«Частный DNS» в настройках самого Android сюда не подходит: ему нужен другой протокол, и интернет пропадёт.

Как выключить, если какой-то сайт не открывается: Chrome → Настройки → Конфиденциальность и безопасность → «Использовать безопасный DNS» → выключить.

Расширение для браузера

Главный способ для сайтов: убирает рекламу и баннеры, прячет окна «отключите блокировщик». Подходит для Chrome, Edge, Яндекс Браузера, Opera, Brave и Firefox.

+Установить расширение

Из магазина — 1 клик. Из архива — 3 шага, один раз.

В магазинах расширения пока нет — оно ставится из архива с этого сайта (или файлом из бота @chisto_ads_bot). Три шага, один раз:

  1. Распакуйте скачанный архив в папку, которую не будете удалять (например, в «Документы»).
  2. Откройте страницу расширений: скопируйте адрес ниже, вставьте в адресную строку браузера и нажмите Enter. В Edge, Opera и Яндекс Браузере адрес тот же.
    chrome://extensions
  3. Включите «Режим разработчика» (переключатель вверху), нажмите «Загрузить распакованное» и выберите папку из первого шага.
  1. Откройте страницу отладки: скопируйте адрес ниже, вставьте в адресную строку и нажмите Enter.
    about:debugging#/runtime/this-firefox
  2. Нажмите «Загрузить временное дополнение» и выберите скачанный архив.
  3. Временное дополнение исчезает после перезапуска Firefox. Насовсем — только после публикации в addons.mozilla.org.

Другой браузер: архив для Chrome и похожих · архив для Firefox

Как выключить, если какой-то сайт не открывается: значок расширения → «Выключить на этом сайте» или «Поставить на паузу везде».

Защита для программ — по желанию

Расширение работает только в браузере. Чтобы реклама и слежка резались ещё и в программах, настройте DNS одним из способов ниже.

Только браузер: Chrome, Edge, Яндекс Браузер

Адрес для вставки

  1. Настройки → «Конфиденциальность и безопасность» → «Безопасность» → «Использовать безопасный DNS».
  2. Выберите «Свой» и вставьте адрес из рамки.
  3. Выключить можно там же, переключателем.
Windows 11
  1. Параметры → Сеть и Интернет → Wi-Fi или Ethernet → свойства оборудования → «Назначение DNS-сервера» → «Изменить» → «Вручную».
  2. Включите IPv4, в «Предпочитаемый DNS» впишите: .
  3. «DNS через HTTPS» → «Вкл. (вручную)», шаблон: .
macOS — для всех программ
  1. Скачайте тот же профиль, что для iPhone.
  2. Системные настройки → Основные → «Управление устройствами» (в старых macOS — «Профили») → двойной щелчок по профилю → «Установить», пароль от Mac.
  3. Выключить: там же, кнопка «−».
Linux (NetworkManager + systemd-resolved)
  1. В файле /etc/systemd/resolved.conf укажите: DNS=# и DNSOverTLS=yes.
  2. sudo systemctl restart systemd-resolved.
  3. Проверка: resolvectl query ad.doubleclick.net → 0.0.0.0.

Роутер — один раз и для всей квартиры

Настроили роутер — и все устройства дома, включая телевизор, защищены без установки программ. Работает только в этой Wi-Fi сети: в гостях и в мобильном интернете защиты не будет.

Адрес для вставки

  1. Зайдите в настройки роутера (обычно в браузере: 192.168.0.1 или 192.168.1.1; пароль — на наклейке роутера).
  2. Найдите «DNS-over-HTTPS» (есть в Keenetic, MikroTik, OpenWrt, ASUS с Merlin) или «DNS-over-TLS».
  3. Для DoT: , порт 853. Для DoH вставьте адрес из рамки выше.
  4. Отключите «DNS провайдера», иначе роутер будет обходить фильтр.

Подробно по моделям — инструкция на GitHub.

Как выключить: в тех же настройках верните «DNS провайдера».

У меня включён VPN

Если VPN работает постоянно, обычные способы (профиль для iPhone, «Частный DNS») не сработают: VPN отправляет все запросы на свой сервер. Поэтому «Чисто» подключается прямо в программу VPN — понадобятся два значения: адрес DNS и список доменов.

Выберите свою программу

Сайты на компьютере лучше закрывает расширение — с VPN оно не конфликтует.

Как выключить: верните прежний DNS в программе и уберите правило со списком.
