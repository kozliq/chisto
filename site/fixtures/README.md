# Тестовая страница

`ad.html` — страница с фальшивой рекламой для проверки расширения.
Без расширения всё видно и внизу «ТЕСТ НЕ ПРОЙДЕН». С расширением — «ТЕСТ ПРОЙДЕН».

Откройте через локальный сервер (правила для `localhost` и `127.0.0.1`):

    cd site && python3 -m http.server 8080
    # http://localhost:8080/fixtures/ad.html
