# Приватность

## Что уходит на сервер

| Откуда | Что | Зачем |
|---|---|---|
| Телефон/компьютер с нашим DNS | DNS-запрос: имя домена (`example.com`) и тип записи | Ответить: адрес или 0.0.0.0 для рекламы |
| Расширение, раз в 12 часов | Запрос файла `/rules/update.json` | Скачать свежие правила |
| Сайт с кнопками | Обычные запросы страницы + 2 DNS-запроса проверки статуса (`example.com`, тестовый домен) | Показать «фильтр жив» |
| Расширение на youtube.com | В базу SponsorBlock — первые 4 символа SHA-256 от id ролика (под них подходят тысячи видео) | Узнать, где в ролике рекламная вставка |
| Расширение, только по вашей кнопке «Отправить в SponsorBlock» | id ролика, начало и конец вставки, случайный id установки | Чтобы вставка пропускалась у всех |
| Бот в Telegram | Ваши команды боту (их доставляет Telegram) | Ответить кнопками. Бот ничего не хранит: ни пользователей, ни сообщений |

## Чего нет

- Трафика сайтов, адресов страниц, содержимого — через сервер идёт только DNS.
- Аккаунтов, регистрации, cookies, аналитики, сторонних скриптов на сайте.
- Журнала DNS-запросов. Расширение не отправляет историю браузера никуда.
- Чужого кода: правила с сервера — это данные. Расширение пропускает только «заблокировать», «разрешить» и подмену на свои пустышки, а CSS — без `url(`, `@import` и селекторов по значению полей. Даже если сервер угонят, через него нельзя перенаправить страницу, снять защиту сайта или подсмотреть введённое.

## Журналы по умолчанию

**VPS (AdGuard Home + Caddy)**
- `querylog.enabled: false`, `statistics.enabled: false` — журнал запросов и «топ клиентов» выключены.
- `anonymize_client_ip: true` — даже если журнал включат, последние октеты IP обрезаются.
- Caddy: директивы `log` нет — журнал доступа не пишется.
- Если владелец включает журнал AdGuard Home: срок хранения задаётся `querylog.interval` (поставьте `24h`),
  видит его только тот, у кого пароль панели (`server/.admin-password`) и SSH-доступ к серверу.
  Включили — допишите сюда дату, срок и кто видит.

**Cloudflare Worker**
- `observability.enabled: false`, в коде нет `console.log` и хранилищ.
- Защита от злоупотреблений: не больше 600 DNS-запросов в минуту с одного IP. Счётчик по IP держит Cloudflare в памяти на минуту (Rate Limiting binding); мы адреса не сохраняем и не видим.
- Cloudflare как хостинг обрабатывает запросы (IP и адрес запроса) по своей политике — это вне нашего кода.
- Ответы пересылаются публичному резолверу Cloudflare (1.1.1.1) или Google — им виден домен, но не ваш IP (запрос идёт от Worker).

## Приложения

- iOS: `PrivacyInfo.xcprivacy` — ничего не собирается, трекинга нет. DoH выполняет сама iOS.
- Android: домены не пишутся ни в файл, ни в logcat. Резервное копирование отключено (`allowBackup=false`).
