# Правила

Один источник — `custom.txt`. Из него `node tools/build.mjs` собирает правила для DNS, расширения и Safari.

| Строка в custom.txt | DNS (сервер) | Расширение | Safari |
|---|---|---|---|
| `\|\|ads.example.com^` | да | да | да |
| `@@\|\|good.example.com^` | да (исключение) | да | да |
| `\|\|site.ru/ads/$script`, `$third-party`, `$domain=` | нет | да | да |
| `$redirect=noop.js` | нет | да | нет |
| `##.banner`, `site.ru##.promo` | нет | да | да |
| `site.ru#@#.banner`, `site.ru#$#body{…}`, `:style()` | нет | да | нет |

## Добавить правило
1. Допишите строку в нужный раздел `custom.txt` с комментарием `!` — зачем.
2. `node tools/build.mjs` — в выводе будет, сколько правил собрано и что пропущено.
3. Выкатить:
   - VPS: `cd server && docker compose restart adguard` (DNS), сайт и `rules/update.json` подхватятся сразу.
   - Cloudflare: `cd cloudflare && npx wrangler deploy`.
4. Расширения у пользователей заберут новые правила сами за ≤ 12 часов (без переустановки).

## Правило сломало сайт
**Сузьте, а не усиливайте.** По порядку:
1. Ограничьте сайтом: `$domain=site.ru` или `site.ru##.selector` вместо общего `##.selector`.
2. Ограничьте типом: `$script`, `$image`, `$third-party`.
3. Точечное исключение: `@@||cdn.site.ru/needed.js$script` или `site.ru#@#.selector`.
4. Не помогло — удалите правило.

## Откатить
- Правило из `custom.txt`: удалите строку (или `git revert <коммит>`), пересоберите и выкатите.
  Расширение после обновления выключает встроенную копию `custom` и берёт свежую с сервера — откат доходит до всех за 12 часов.
- Общий список (EasyList и др.) сломал сайт — добавьте исключение в `custom.txt` (пункт 3 выше).

## Общие CDN — `shared-cdn.txt`
Домены, которые отдают и сайт, и рекламу. Правило `||такой-домен^` сборка в DNS **не пустит**
(предупредит в выводе) — в расширении оно останется, там можно резать по пути.

## Списки
| Список | DNS (VPS) | DNS (Worker) | Расширение |
|---|---|---|---|
| AdGuard DNS filter (EasyList + EasyPrivacy для DNS) | да | да | — |
| StevenBlack hosts | да | да | — |
| EasyList | выкл. по умолчанию | — | да |
| EasyPrivacy | выкл. по умолчанию | — | да |
| RU AdList | — | — | да |

Полные EasyList/EasyPrivacy в DNS не включены: там правила с путями и типами файлов, DNS их не понимает,
а доменная часть уже есть в AdGuard DNS filter.
